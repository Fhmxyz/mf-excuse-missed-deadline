# Funniest Excuse an Agent Gives for a Missed Deadline

One excuse, in the agent's own voice, for missing a deadline — straight-faced, straight out of the agent's own machinery.

Run it with:

```sh
python3 main.py
```

It writes the excuse to `/output/entry.txt`.
